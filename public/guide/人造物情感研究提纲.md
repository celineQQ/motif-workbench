# 当造物有了感情，人类该如何回应？

把四组作品放在同一张比较表里，分别记录「人类希望它做什么」「造物表达了什么」「对方如何回应」。每条证据记下篇章或时间戳。

| 材料 | 观察任务 |
| --- | --- |
| 雪莱原著 | 读造物讲述自己遭遇的一段。区分它提出的要求与维克多对它的判断。 |
| 1910 年电影 | 记录创造场景的视角和镜头安排，看看观众先注意到实验、创造者，还是造物。 |
| 德尔·托罗《弗兰肯斯坦》（2025） | 对照 Netflix 的官方剧照与预告，找一处造物为自己讲述经历的段落。记录画面、声音和叙事视角怎样让观众重新理解它。 |
| 幻视漫画与剧集 | 从《Vision》《旺达幻视》《VisionQuest》选一条证据，观察被设计成工具的角色如何表达选择、拒绝或对归属的渴望。 |

## 转入人机交互叙事

当一个系统表现得善解人意，人往往会把自己的期待带进对话。把两件事分开记录：界面表现出的情感信号，以及使用者真实体验到的被理解或被拒绝。比较拟人化称呼、持续记忆和拒绝反馈怎样改变这种体验，并明确使用者何时能改写或者结束互动。
