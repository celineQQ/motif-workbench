# MOTIF · A Room of One’s Own

MOTIF is a local-first creative workbench. Its 3D room leads into a workspace for conversations, research assets, editable documents, notes, tasks and vision boards.

The public walkthrough uses From Frankenstein to Vision to show a research question becoming a draft and an organised archive. It runs scripted responses in the actual interface and requires no API key.

Run npm ci and npm run dev to start the full workbench. For live streaming responses, configure your own OpenAI-compatible endpoint, model and API key in Settings.

To publish, push this repository to GitHub. In Settings → Pages select GitHub Actions, then run Publish MOTIF portfolio. This publishes the portfolio build. The illustrated guide is also available under guide/index.html.
